## Glossary

| Term | Meaning |
|---|---|
| Reel | The 45-second showreel, `assets/video/reel.mp4` |
| Clip | A 3–5 s silent loop cut from the reel (`assets/clips/`) that plays on a work tile |
| Tile | A project card in Selected work |
| Case page | A project's own page under `work/`, generated by `scripts/build_work.py` |
| HD hero | A case page header streaming the project's Vimeo film in background mode (`hero_vimeo`) |
| Accent | The neon blue `#00a6ff` (`--accent`) |
| Owner | Shane Valdez (GitHub ShaneRealm), who commissions the site for Taylor |
| `?v=` stamp | The cache-busting version on CSS and JS links |
